# Chamada

O título empilhado dos materiais: uma linha em `ink`, a palavra-chave em `fogo`, e uma linha de fechamento em `ink`.

- `estilo="cartaz"` (Anton, CAIXA ALTA) para convites e chamadas de ação: "FAÇA SUA / INSCRIÇÃO / HOJE MESMO!".
- `estilo="titulo"` (Archivo Black) para posts de conteúdo, com frase e ponto final: "Uma experiência / que transforma."
- Apenas uma linha em fogo por chamada. Máximo de três linhas.
- Passe `antes`, `destaque` e `depois` (cada um opcional); `as` escolhe a tag (padrão `h2`).
