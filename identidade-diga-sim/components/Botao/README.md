# Botao

Botão de ação para site, formulário de inscrição e materiais digitais. **fogo** (padrão) uma vez por tela, para a inscrição; **contorno** para as demais ações.

- Texto curto, verbo primeiro, sem ponto: "Quero me inscrever", "Saiba mais".
- O rótulo vai em caixa alta pelo próprio estilo; escreva-o normalmente.
- Aceita todas as props de `<button>`.
