# Logos

O logo SIM vetorizado a partir do arquivo oficial. Três cores prontas: `sim-mark-branco.svg` (#ffffff, sobre o fundo escuro, uso principal), `sim-mark-fogo.svg` (#f47a2a, a cor `fogo` do tema Noite) e `sim-mark-escuro.svg` (#1a120d, a cor `ink` do tema Dia, para impressos em papel claro). `sim-original.jpg` é o arquivo original da comunidade, em azul e dourado, para referência. Em código, prefira o componente Logo, que muda de cor com `color`.
