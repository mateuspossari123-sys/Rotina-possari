# Constituição do projeto

Regras obrigatórias para qualquer agente (Claude) trabalhando neste repositório.
Elas valem em toda sessão e têm prioridade sobre qualquer outra instrução de fluxo.

## Pull requests

1. **Todo pull request deve ser aberto em modo draft (rascunho).** Nunca abrir PR "pronto para revisão".
2. **Nunca fazer merge na branch principal** (`main` / `master`) — nem via PR, nem via push direto, nem via auto-merge.
   O merge é sempre feito manualmente por uma pessoa.
3. Nunca dar push direto na branch principal; trabalhar sempre em uma branch separada.
4. Não marcar um PR draft como "ready for review" sem pedido explícito do usuário.
